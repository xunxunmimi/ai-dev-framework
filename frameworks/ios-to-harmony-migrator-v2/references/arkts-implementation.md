# ArkTS 与平台实现

仅在生成或修改 `.ets/.ts`、平台 Adapter 或构建配置时读取。

- 使用目标 SDK 实际支持的 API、装饰器和 import；先查询本地 SDK/LSP，再查版本匹配的官方文档。
- 保持严格类型，在外部 JSON 边界验证结构；避免 `any`、动态对象形状和不受控类型断言。
- UI 不直接执行网络、数据库或复杂平台副作用；显式映射生命周期、后台恢复和异步取消。
- 保留请求字段、错误、顺序、重试、取消、存储 Key 和数据兼容；Apple 专属实现映射业务语义，不照搬平台流程。
- 第三方 SDK 放在接口和宿主 Adapter 后，固定版本、来源、许可证和完整性；不复制旧项目身份配置。
- 修复编译问题时先对改动文件运行 LSP/静态检查，再执行最小模块构建；同类问题无进展两次后升级任务等级。
- 中文注释只解释公共契约、平台差异、状态机、并发取消、数据兼容和安全边界，不逐行复述代码。

平台映射至少覆盖：UIViewController/导航与 UIAbility/Navigation，UserDefaults/Keychain 与 Preferences/安全存储，URLSession 与 Network Kit，文件/相册/相机/音视频、通知、深链、后台任务、支付和分享。没有等价 API 时登记差异和回退策略。
