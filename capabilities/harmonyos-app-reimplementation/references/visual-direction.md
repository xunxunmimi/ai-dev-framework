# Logo + 参考图 → 全量新 UI

实际查看 Logo、参考图及源应用各状态。记录每张参考图哪些视觉元素可借鉴、哪些属于品牌/版权不可复制；参考图中的文案不是业务文案来源。缺图不臆测，不把已有设计当“无设计”。

输出可实现的 ArkUI 视觉规范：色板及语义色、字体层级、间距、网格、安全区、圆角、阴影、导航与标题位置、按钮状态、表单/键盘、卡片/列表、弹窗遮罩、图标笔画和动效。区分观察到的元素与自行推导的选择；尺寸按设备单位验证，不把网页 px 当平台规范。

先用首页、一条复杂业务流程、一个输入状态与一个弹窗验证方向，然后推广全部页面。只在用户保留设计决策或方向存在实质冲突时等待确认；已明确授权的设计与实现继续。所有自有布局、icon 与资源都纳入映射清单；不是只改主题色或首页。

布局可改变，动作语义、信息、入口可达性、业务顺序与文案不得悄悄改变。每个页面覆盖加载/成功/失败/空/禁用/会员差异、二三级导航、返回与重复进入。确认全屏遮罩覆盖安全区及系统栏符合设计；不要拿局部 overlay 冒充全屏弹窗。

图标/插画按新的统一风格重绘，资源使用有意义的英文名字。不要任意重命名系统要求的资源或生成文件。Logo 无文字时不自造品牌名；含文字时不视为修改其余业务文案的授权。动效需真渲染检查节奏、裁切、循环、尺寸和背景；JSON 成功加载不是效果一致的证据。

验证以用户要求的正常系统字号及目标真机为基准；大字号专项默认不作为本任务门槛，也不擅自禁用动态字体。记录设备、系统/API、字号和屏幕状态。系统授权弹窗、系统分享/支付/打印面板、SDK 自带页面列出不可自定义或范围外差异，不假称重绘完成。
