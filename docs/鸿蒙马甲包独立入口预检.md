# 鸿蒙马甲包独立入口：只读预检切片

用户流程：制作与验收期间只用马甲包 Skill；验收后才按明确决定进入鸿蒙日常框架。日常框架不是隐藏前置依赖。

本工具只负责只读预检。新目标需要安装时，使用[独立安装入口](鸿蒙马甲包独立安装.md)显式安装 Skill；该入口不安装日常框架，也不转换已有生命周期。

```sh
python3 installers/plan_harmonyos_restyle.py --source /absolute/source --project /absolute/target
```

源／目标先具备各自真实授权的读取策略。入口复用现有安装器所有路径、独立目录、策略及安装所需权限检查；额外核父目录真实类型、已有规则／指令／任务／升级／暂停记录。未知、不可读不能按不存在处理。源只读，目标无写入，不设置 confirmed，不生成策略，不取得或清除锁。完整策略仍是明确授权选择，不能为让预检通过而默认扩大范围。

`preflight-only` 仅代表本次只读检查通过；`executionSupported: false` 明确表示不能据此开始正式制作。观察不是并发冻结或停写证明。`blocked-existing-context` 返回需正式审阅的控制路径，不读取或覆盖其业务内容。输出含本地路径及控制元数据，应按项目权限保管。

已装日常框架的项目保持原样，不能删除清单假装新项目，也不能只改 AGENTS 或 lifecycle 绕开路由。当前没有已验证的正式模式转换路径。可继续现有许可范围内的只读需求、参考图和源码分析，但不能声称独立执行已经恢复。

后续正式能力必须补齐独立生命周期、安全任务所有权、证据和恢复契约，以及已安装项目的显式交接；所有原安全约束保持。验收后接日常框架是单独的明确动作，不能自动把构建通过或测试完成当作用户验收。
