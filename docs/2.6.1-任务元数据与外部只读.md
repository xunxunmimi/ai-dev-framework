# 2.6.1 更新与跨机复制

本补丁增加单路径 Xcode UI 元数据确认和任务专用临时外部只读许可。精确合同、限制和操作见 shared/context-engineering/task-control.md 与 read-boundary.md；示例和合成测试不授权任何真实项目或其他电脑。

整个运行框架以本发布包内 `AI开发框架/` 目录为复制单位。包包括 VERSION、README、frameworks、shared、installers、capabilities、docs、evals（定义及合成夹具）；不含 releases、archive、历史评测结果、机器注册、凭据和缓存。历史文档中的绝对路径是旧示例，须按目标机实际路径替换，不能视作注册信息。

在 CCMac 先把旧框架目录改名备份，再将解压后的完整目录放到 `${HOME}/Desktop/MyProject/AI开发框架`；核对清单和哈希后先对 Ruler 运行 `installers/audit-project.sh ${HOME}/Desktop/Ruler`、`installers/update-project.sh ${HOME}/Desktop/Ruler --dry-run`。确认项目身份、受管漂移、当前任务状态及源路径后才按该机实际授权执行更新。不得重新 adopt 或重建基线来消除漂移；更新脚本备份其受管文件，回滚遇后续用户修改会拒绝覆盖。安装后仍需重新核实 Ruler 中该任务和文件的实际哈希，再明确执行元数据确认；不能把其他机器的哈希当现状。

全局技能注册每台机器独立，项目升级和全局注册都不会自动运行。此补丁不自动修改任何业务项目、设备或其他电脑。

回滚项目升级后，旧安装清单的 suiteRoot 仍指向升级前的原路径。若该路径现为 2.6.1，恢复项目受管文件并不自动恢复可运行：还须按旧清单版本与哈希安全恢复对应旧套件路径，或先经明确审计设计路径重绑定；不要只做项目 restore 就宣称完整回滚。
