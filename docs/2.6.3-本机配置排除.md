# 2.6.3 本机配置排除

新增按路径分量、大小写不敏感的保守规则：以 `.local` 结尾或包含 `.local.` 的文件和目录，在查询类型、进入、打开和摘要前排除。包括 `sample_app_account.local.json`、`sample_app_account.dev.local.json` 及其大小写变体；同名非敏感文件也会被排除。完整模式只表示其声明范围完整，不代表排除内容被检查；v2 覆盖和证据不能沿用。

不同命名的敏感文件不能保证被识别，应在读取前明确配置 deny 或限制允许范围。链接及硬链接不能用于别名绕过。外部构建和测试子进程不由此边界约束，禁止读取真实凭据时必须使用确认无凭据的隔离环境。项目须审计并升级到新版本后重新绑定任务；绝不改写旧版固定快照。
